# Logo

Generated with the built-in image_gen tool. `logo.png` is the original generated image; `app.ico` contains resized PNG frames for Windows (16, 32, 48, 64, 128 and 256 pixels).

## Prompt

Use case: logo-brand. Create a single polished app icon for M365 Debloater, a Windows utility that tidies Office components. Symbol only, no text. An original geometric document stack with a clean subtraction cut and a small four-point cleanup sparkle; bold simple silhouette legible at 32px. Flat vector-like raster, crisp edges, restrained blue and teal colors suitable for a dark navy app header. Centered square composition with modest padding, transparent background. No Microsoft logo, no watermark, no mockup, no extra variants.
